# Safari Crest 🌿🦒

**Discover Africa. Explore Nature. Protect Wildlife.**

## About the Project

Safari Crest is a group web development project focused on promoting responsible ecotourism, wildlife conservation, and nature-based travel experiences in Kenya.

The website provides visitors with information about African safari experiences, travel opportunities, outdoor activities, and conservation initiatives. It is designed to inspire people to explore Kenya's natural beauty while encouraging responsible tourism and environmental protection.

The project focuses on creating a visually appealing, user-friendly, and responsive website that connects visitors with nature and encourages sustainable travel.

## Project Objectives

- Promote responsible ecotourism and wildlife conservation in Kenya.
- Provide information about safari experiences and outdoor activities.
- Create an attractive and easy-to-navigate website.
- Encourage visitors to appreciate and protect wildlife and natural environments.
- Apply practical HTML and CSS skills in a collaborative group project.

## Website Features

- **Homepage:** Introduces Safari Crest and highlights nature-based travel experiences.
- **Services Page:** Presents safari-related services and travel experiences.
- **About Page:** Provides information about Safari Crest, its purpose, and its commitment to conservation.
- **Contact Us Page:** Provides visitors with information on how to contact the organization.
- **Nature-Inspired Design:** Uses natural colors, wildlife imagery, and visual elements inspired by African landscapes.
- **Responsive Navigation:** Helps visitors move between the website's pages.
- **User-Friendly Interface:** Uses clear layouts, readable text, and consistent branding.

## Technologies Used

- **HTML5** — Structures the website's pages and content.
- **CSS3** — Handles styling, layouts, colors, animations, and responsive design.
- **JavaScript** — Used where applicable for interactive interface elements.
- **Git and GitHub** — Used for version control and collaborative development.
- **GitHub Codespaces** — Provides a cloud-based development environment.

## How to Run the Project

1. Clone or download the project repository from GitHub.
2. Open the project folder in Visual Studio Code or GitHub Codespaces.
3. Check that the HTML files, CSS stylesheets, and image assets are in their correct locations.
4. Open `homepage.html` in a web browser, or use a development server such as the VS Code Live Server extension.
5. Navigate through the website using the available menu links.
